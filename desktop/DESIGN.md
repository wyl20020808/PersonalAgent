# PersonalAgent 桌面视觉规范

按用户后续偏好，默认采用 Premium Light Desktop Dashboard：白色面板、柔和灰蓝工作区、细边界与低对比渐变。主强调色为克制的深青绿，状态色统一为绿色成功、玫瑰红失败、沙金警告。紫灰只用于 Mock 标签，避免彩色统计卡片。窗口背景也使用浅色，启动不出现黑色闪烁。

左侧 224px 导航、67px 顶部路径区、34px 内容边距，1280 宽度适当收紧。标题 29px，面板标题 15–19px，正文 12–13px，次级元数据 10–11px；使用 Windows Segoe UI 与 Microsoft YaHei UI 系统字体，代码使用 Cascadia Code/Consolas。图标统一 Lucide 1.7 描边。卡片圆角 12px、控件 7–8px、模态 14px，边框与阴影层级统一。

Dashboard 用一个当前焦点面板和协作状态面板强调正在做什么，最近记录使用精致列表。运行详情采用任务轨迹与真实证据选项卡，配持久化会话侧栏。交付使用文件列表、带增删背景的只读 Diff、精确审批绑定和独立操作按钮。设置展现真实路径、可信配置、全局预约记录和减少动效开关。

页面进入 200–250ms、悬停 160ms、进度变化 400ms。支持系统 prefers-reduced-motion 及持久化减少动效设置。空状态解释下一步，读取时显示加载反馈，失败面板保留具体原因，暂停明确剩余预算不重置；不可用操作禁用且说明原因。不展示模拟进度或虚构“在线”认证状态。

验收使用实际 Electron 窗口截图检查 1280×720 和 1440×900，而不是单独渲染的静态设计稿。

## V0.3C 最终用户确认的群聊布局

一个共同聊天窗口，按时间交错排列：你与 CC 的头像靠左，Codex 的头像与气泡靠右；不是左右两个独立聊天窗口。Controller 普通阶段事件居中、轻量展示，测试和错误保留可展开证据。主区域使用全部可用宽度，右侧详情默认隐藏，聊天标题栏按需展开。工作台等详情页面继续存在。

聊天区域边距 29–42px，消息间隔 33–38px；普通气泡最大宽度约 76–82%，短消息按内容宽度收缩。正文 13px、行高 1.95，元信息 10–13px。用低饱和白、暖白和浅青区分角色，减少硬卡片堆叠。顶部不重复大型 Dashboard 标题，底部输入区始终留出完整空间。1280 窗口保持同一条聊天时间线，不拆为两个面板。

任务计划、测试、Diff、长文本折叠；右上角提供截图和待决策入口。截图画廊与人工决策位于同一工作区，放大查看支持 Escape、焦点约束和前阶段对比。所有视觉决策仍需明确文字与勾选，查看图片不会自动批准；正式交付保持独立页面和原生确认。

## Codex 式简洁布局（覆盖上文的导航、顶部路径区与群聊标题栏尺寸）

整体对标 Codex：左侧 48px 图标栏放功能入口（项目群、工作台、新建任务、运行详情、成果交付、运行记录，底部设置），其右 252px 侧边栏只放「新建会话」和「项目 → 会话」树；没有项目的会话单独列在下方。项目行悬停出现小笔按钮，直接在该项目内新建会话并沿用该项目最近的设置。

不再有顶部路径栏和页面大标题；环境信息与刷新状态放在设置页。聊天区无卡片边框，标题栏 46px 只显示会话名、项目名、运行状态、「···」菜单（更换项目、运行详情、滚动跟随、查看方式、角色筛选）和右侧详情面板开关。项目详情是默认隐藏的 300px 右侧面板，开关状态本地记忆。

输入区是一个圆角框：上方文本框，底行左侧为累计预算与真实额度确认，右侧为消息用途下拉和 30px 圆形发送按钮。样式集中在 `src/codex.css`，最后加载并覆盖旧规则。脚本 `capture-codex-layout.mjs` 用真实 Electron 窗口截图验收。
