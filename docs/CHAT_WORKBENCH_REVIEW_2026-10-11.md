## 已确认的问题及修复

| 问题 | 影响 | 本轮处理 |
| --- | --- | --- |
| 每次文件事件都启动一次完整轮询，并各自创建新定时器 | 并发读取、重复刷新、后台负载增长 | 提取串行刷新循环，事件突发合并为一次后续读取，失败后重试，卸载后停止 |
| 文件监听缺少错误处理和 Renderer 生命周期清理 | 监听泄漏；监听错误可能退出主进程 | 限定可信来源和订阅数；刷新、崩溃、销毁、退出时释放；监听目录以覆盖文件替换；预加载层引用计数；监听失败保留轮询 |
| 新 Run 出现时清空输入和附件 | 等待过程中正在写的下一条需求丢失 | 草稿重置与 Run 刷新解耦；切换会话时才清理；附件异步读取与发送回包绑定原会话 |
| 纯图片无法提交 | 必须额外输入文字 | 允许仅附件发送，使用明确的默认文字 |
| 未支持的文件只保存名称；文本静默截断；超过数量静默丢弃 | 界面显示成功，但 Agent 收不到完整材料 | 文件类型、字节数、编码与批次数量双端校验；完整批次失败明确报错；不静默截断；读取期间不能发送 |
| 重复消息只比对文字，不比对附件 | 同一消息 ID 替换附件被当作已完成重试 | 持久化附件摘要；重试同时核对文字和附件内容 |
| 附件能附在不接收附件的恢复/验收操作上 | 附件被清空却未交付 | 仅在新会话开发需求中启用；其他用途明确拒绝，不清空 |
| 附件保存边写边校验，后续附件失败留下半批文件 | 孤立文件、难以判断交付完整性 | 写入前验证整个批次；写入异常只清理本次新建文件 |
| 文件浏览插在消息区，目录被当成普通文件 | 挤占聊天、点击目录报错 | 移至右侧详情；按目录展开、返回上级、筛选当前目录，显示截断提示 |
| 快速切换文件时旧请求覆盖新结果 | 预览与选中项不一致 | 请求序号校验；切换项目、关闭预览时作废旧结果 |
| 任意二进制被解码成乱码，SVG 被作为图片 | 预览不可读且增加不必要的渲染面 | UTF-8 严格解码；SVG 只显示源码；拒绝二进制；读取前后检查文件身份与大小，限制单次内存读取 |
| 消息左右排列违背原需求，复制按钮覆盖内容，加载反馈不足 | 决策/执行难区分，提交过程不明确 | 按消息职责排列：决策左、执行右；复制按钮预留空间并显示失败反馈；附件缩略图扩大、逐项移除；补读取和提交状态，无清空按钮 |

## 尚未完成的能力与边界

1. **原生多模态仍未完成。** 当前保存图片字节并将附件路径交给 Agent 使用原生读取工具；尚未接入 Claude image blocks、Codex `local_image` 和 OpenCode file parts 的统一传输。路径和提示文字不等于模型已读取像素，不能把本轮测试描述为真实识图通过。下一阶段应将可信附件清单绑定到 Run，再分别接入各后端的原生输入，并验证恢复后的内容哈希。
2. **历史图片目前展示附件名称和大小。** 发消息前有缩略图；发出后还没有按需读取、完整预览和安全导出的统一附件接口。
3. **事件通道是本地文件变更通知 + 游标补读。** 本轮解决生命周期和并发问题，没有把通知冒充服务器逐 token 传输。每次新事件仍可能重新读取完整审计文件；超长会话需要持久索引或增量审计读取。
4. **文件浏览为目录级浏览。** 当前目录最多展示 1,000 项，明确提示；不是全项目全文索引。大文件预览限制为 2 MiB；文本显示至 200,000 字符并标注。这些是界面资源保护，不是 Agent 执行时限。
5. **安全策略未扩大。** 未修改 Work/Idle 策略、Hook、系统权限或真实数据。没有操作系统级隔离验收；原生 Shell 仍不能因为这些 UI 测试就称作绝对安全。
6. **未运行付费模型端到端测试，也未操作系统剪贴板进行验收。** UI 粘贴测试仅构造隔离页面中的 ClipboardEvent。复制失败现有明确提示，原生右键菜单保留。
