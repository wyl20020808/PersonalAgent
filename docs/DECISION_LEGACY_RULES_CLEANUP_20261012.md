## 已解除的旧方法限制

- Context 模块引用可选，缺省或空数组均可执行；显式引用仍校验存在性。
- 规划阶段可在授权范围内修改业务文件；保留规划观察记录，并将实际路径、范围和完整证据引用送给后续决策者验收。
- checked_files 的选择、数量、源码/文档/测试分类及测试模块组织由决策者决定，保留真实文件、哈希和路径保护。
- 多决策者的新配置默认 auto，主决策者在初稿中选择 discussionRounds，可为零或任意非负整数；旧显式数字继续执行。每次调用仍遵守用户配置的超时，恢复复用已成功步骤。
- 多轮交换仅传上一轮意见，完整历史可按引用查阅；不反复传所有历史意见全文。
- 清除任务验收条目、模块关联、契约确认和阶段映射的固定数量上限，清除讨论意见的固定条数上限。
- 清除 README、界面及治理文档中空 tests 必须人工验收、决策者 pass 仍等用户、Controller 观察告警自动否决等旧表述。
- Context 审查提供参考资料，决策者选择与实际影响相关的核查方式；如实记录已经核查的契约，不伪造 accepted 或用户确认。
