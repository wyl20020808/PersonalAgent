# 附件预览边框和文件名占用空间

状态：已解决（任务工作区内，未集成运行版）。

用户反馈图片附件仍有细边框和文件名，占用预览空间。原因已确认：图片卡片继承通用 `.attachment-chip` 的边框，并额外渲染名称及内边距。

本轮移除图片卡片边框、底色、内边距和可见文件名，保留无障碍名称、预览和独立移除按钮；文本附件仍显示名称。缩略图按比例展示，放大预览移除文件名及分隔边框，减少内边距。聊天消息和输入区域使用淡底色区分，移除外边框及阴影。

验证：`desktop` 目录下 `npm run check`、`npm run test:workbench-ui` 和 `git diff --check` 均通过。后台 Electron 截图已人工查看；证据为 `.v3c3/workbench-preview/workbench-borderless.png`。旧截图被占用导致首次写入失败，改用新的截图文件名后通过，未关闭用户窗口或操作桌面。未进行真实 Agent 调用或 Controller 独立验收。

下一步：按既有交付流程审查并整合。此记录更新此前多模态文档中关于图片文件名和预览外观的描述。
