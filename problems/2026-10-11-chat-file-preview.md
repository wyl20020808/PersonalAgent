# 聊天文件卡片无法打开及缺少代码变更预览

- 归属：PersonalAgent 桌面聊天工作台。
- 现象：Codex 文件操作显示文件路径，但点击无法打开文件；查看变更只能展开原始 diff 文本。
- 证据：用户提供的截图；开发基线 `dev d2fe3e6` 的 `GroupWorkspace.tsx` 将文件路径渲染为无事件处理的 `span`。
- 影响：无法从聊天直接检查代码内容和修改位置，必须手动寻找文件。
- 已确认原因：文件卡片没有连接已有的右侧预览标签页，缺少带行号及语法高亮的 diff 渲染组件。
- 修复：增加只读的、绑定 Run 和审计事件的文件预览接口；卡片打开右侧标签页，支持文件/变更切换、增删行统计和变更汇总。
- 证据范围：优先使用同一次 Agent 调用的审计 diff；原有有限 Git 观测可能含此前修改，界面明确标注。缺少历史 diff 时获取当前工作区与 Git HEAD 的实际差异，包括未跟踪的新文件。没有 Git 提交时使用空文件基线；没有可用基线时不伪造历史内容。
- 当前状态：实现及本地验证完成，待正式交付、DEV 集成及用户实际验收。
- 下一步：按项目交付审批流程审查及集成；保留运行中的 Session、Run 和已有用户修改。
