# 聊天消息过宽、运行命令默认暴露正文

状态：已解决（任务分支内，未集成运行版）。

用户截图显示执行者、决策者和 Controller 的短消息占用过宽，长命令默认显示影响阅读。当前分支的消息样式包含 width:100% 和多处 76%–94% 的宽度上限，单条命令使用普通正文渲染，命令组折叠后仍显示首行。

本轮将顶层消息改为按内容收窄，最大为聊天内容区的 50%；内嵌事件使用父消息宽度，避免重复减半。元信息允许换行，长路径允许断行。运行命令默认折叠，点击展开完整正文；折叠命令组不再显示命令首行。错误消息仍保留原有可见失败原因。
