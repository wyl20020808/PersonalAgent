# 聊天侧栏提醒点缺少已读语义

- 现象：用户点击会话后，黄色提醒点一直显示。
- 原因：App.tsx 仅根据 paused/failed/stopped 判断黄点，没有保存已查看事件。
- 修复：在本地 renderer 存储中保存每个会话已查看的提醒版本。版本绑定最新 Run、状态、更新时间和原因；点击会话或从运行列表进入聊天时记录。普通轮询和会话改名不会重新显示同一 Run 的提醒，新事件仍会提醒。没有 Run 的会话以会话更新时间回退。
- 语义：已读不等于问题解决；不修改 Run 状态、恢复任务或批准成果。绿色运行状态继续显示。存储不可用时，本窗口仍可消除提醒，但重启后的持久性无法保证。
- 验证：Controller 构建、桌面 typecheck/build 通过；`rtk proxy node desktop/test/validate-read-indicator.mjs` 的 8 项离屏 Electron UI 检查通过，覆盖点击消除、其他会话不受影响、轮询不复现、新事件再提示、普通元数据变化不重复提醒、重新加载保持已读、运行指示保留、任务状态不变。输出 `.v3c3/read-indicator/result.json`。
