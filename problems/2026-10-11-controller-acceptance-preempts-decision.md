# Controller 抢占决策者验收职责

- 状态：流程实现及全量自动回归通过；本轮整合本地 TEST，DEV 正式更新与修车现场验收仍待安排。
- 归属：PersonalAgent 的 Controller 调度与验收流程。
- 现象：DEV 最新汽车卡死 Run `7c35390b-704c-4ce7-97e2-6a021a1af9c6` 的执行者结束后，Controller 因 `tests: []` 直接暂停，决策者没有收到成果验收调用。
- 证据：该 Run 第 6 轮原生执行结果和后续审计依次记录 `native-result`、`verify`、`paused`；暂停原因为 `No independent acceptance tests configured; human verification required`，只有规划调用，没有审查调用。已有无关 Diff 空白告警也被程序归入失败项。
- 已确认原因：旧状态机先执行 Controller 的固定检查，再调用决策者；空测试门禁直接阻断审查，Controller 同时参与成果裁决。
- 用户明确的职责修订：执行者提交成果；决策者选择验证方法并验收；用户最终确认。Controller 仅传递信息、保护上下文、调度、恢复、审计和记录授权，不判断成果成败。
- 实现：程序检查不再进入任务验收和新流程的交付确认。审查后等待用户；明确聊天验收绑定当前成果；旧暂停 Run 恢复不重放执行者；观察告警交给决策者和用户判断。
- 验证：专用本地回归覆盖空测试、故意失败的配置命令不执行、用户确认、返工、审查终止、旧 Run 恢复、成果变化及正式交付。独立小仓库真实 Claude/Codex Run `e9d766c8-220e-4832-a486-fb2b096864ea` 已完成规划、执行、决策者亲自验证，返回 human 后交用户；Controller 没有独立检查事件，也没有自动确认。小仓库不是修车验收。
- 限制：未替换活跃 DEV，未修改原修车 Run，未验证汽车现场。旧测试已迁移到决策者验收与明确用户确认的契约，保留恢复、依赖、锁和证据防篡改覆盖；核心 460/460、桌面 133/133，全量自动回归通过。
