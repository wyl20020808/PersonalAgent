# 同项目独立工作树无法并行归组

状态：部分解决，待 DEV 实装及真实任务验收。

用户要求现有 OpenWorld 校园任务与新小地图任务在同一个 DEV 窗口、同一个项目下并行。原 Session 的项目展示及执行互斥均使用同一个 `projectPath`：原路径启动第二任务会排队，改用独立工作树则变成另一个项目分组。

已确认原因：`SessionStore.sendLocked` 按实际 source 排队，`App.tsx` 也按实际目录分组；此前没有独立的项目归组字段。直接取消排队会破坏同目录写入互斥。

修复：增加经 Git 工作树归属验证的 `projectGroupPath`，展示归组使用该字段，执行授权和锁继续使用实际目录；增加“新建并行会话”入口绑定已有任务工作树。旧 Run / Session 不迁移，原任务不被此修复中断。

验证：构建、类型检查通过；Session / Service 81 项通过，最终校验调整后三项复验通过；headless UI 四项通过。详见 `docs/PROJECT_PARALLEL_WORKTREES_V1.md`。

剩余：DEV 仍运行校园任务，不能覆盖活跃源码及构建产物。需安全节点升级、原 Run 恢复及小地图真实运行。此缺项暂阻碍用户要求的最终执行效果。
