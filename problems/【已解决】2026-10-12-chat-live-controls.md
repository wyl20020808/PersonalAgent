# 聊天计时冻结、运行控件缺失与头像背景

- 归属：PersonalAgent 桌面聊天 UI。用户报告右上角计时不逐秒更新、运行中的波浪和暂停按钮缺失、头像有圆形背景。
- 已确认代码原因：`publicRun.active` 与 `thread.timing` 原先仅查询当前 DesktopService 的 `children`。由 CLI 持有 Run 锁的活动 Controller 不在该 Map 中，会被当作非活动 Run；已有秒级刷新和暂停控件因此无法工作。未读取或修改用户截图对应的实际 Run，不能断言该 Run 的具体进程状态。
- 修复：复用 Controller 的 `lock.json` PID 存活判定，统一活动状态与实时计时；缺失、损坏、无效或已退出 PID 的锁保持非活动。头像保留原尺寸与品牌图案，移除背景、边框和阴影。
- 状态：已解决（TEST 源码已整合，当前运行实例未更新）。专项服务回归、完整桌面回归 147/147 及隔离无头 UI 检查通过；用户当前实例的现场视觉验收仍 pending，不冒充已完成运行版验收。详见任务验证文档。
- 验证边界：开发者自测，无真实模型调用；无头页面核对执行和决策计时变化、透明头像、五条波浪动画、暂停 IPC 及退出后隐藏。未进行用户现有 Electron 实例的现场验收或重启。
